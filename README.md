SleepGuard「绿色确认版」v1.7.0 —— 构建与安装
基于 SleepGuard 官方 1.7.0（源码提交 `0a252e350e18fe8bb2cd9049147051c8a49704f2`）修改，专门用于解决自动锁屏后必须返回 App 按「开始」的问题。
> **注意：本文件包是源码补丁和 GitHub Actions 自动构建配置，不是 APK。** 此会话没有 Android SDK，暂时无法编译 APK，也没有在小米 12S Pro / 澎湃 OS 上实机测试。不要将本包当作安装包。
设计的交互规则
首次打开应用：选 Video，点击「开始」。
红圈出现：单击红圈代表你还醒着，立即开启下一轮计时。不需要双击。
没有点击红圈：按原版逻辑暂停媒体、锁屏。与原版不同的是，后台服务会继续待命，不再立即停止。
下一次解锁手机：屏幕上方出现一个绿色的 「继续监测」 按钮。点击绿色按钮则自动开始下一轮计时，不用返回 SleepGuard App 按开始。
解锁后30秒内不点绿色按钮：SleepGuard 自动停止，不再弹出红圈。这让你白天解锁手机时不会无意中继续被打扰。
你手动按电源键锁屏：不是 SleepGuard 自动锁屏，重新解锁后直接继续监测，不会出现绿色确认按钮。
应用内或常驻通知按「停止」：彻底停止。
为什么不在锁屏画面上弹绿色按钮？应用没有权限绕过系统锁屏，而且睡着时不应亮屏，因此只会在下一次解锁后显示。
此版本不检测真正的「最后一次触摸屏幕」，也不局限于小红书；它仍通过每隔设定时间弹出红圈来检测是否清醒。
用 GitHub Actions 生成 APK（手机/电脑皆可操作）
打开 GitHub，新建一个私有空仓库（例如 `sleepguard-green-build`）。
选择 Add file → Create new file。
输入文件名 `.github/workflows/build_green_confirm.yml`，把 ZIP 中此文件的完整内容复制进去，再点击 Commit changes。
打开仓库 Actions 页，左侧选择 Build SleepGuard Green Confirm APK，点击 Run workflow。
运行成功后，在该次运行最下方的 Artifacts 中下载 `SleepGuard-GreenConfirm-v1.7.0-APK`。
解压下载的 ZIP，得到 `app-debug.apk`；发送到小米手机并安装（系统会要求允许该来源安装应用）。
安装的是独立应用 SleepGuard 绿色确认版。与原版包名不同，可以并存；同一时间只启动其中一个，否则会出现两个红圈或重复锁屏。
在绿色确认版中完成权限授权：显示在其他应用上层、设备管理员（只为锁屏）、通知、后台电量无限制。必要时打开后台自启动。
工作流下载原版源码并校验关键文件哈希，再应用补丁、编译成 Debug APK。安装包不是原作者签名的官方 APK。
建议先做四项测试
把 Video 检查间隔改为 1分钟、超时改为 15秒。
开小红书，等红圈弹出，点击一次；1分钟后应再次弹红圈（正常循环）。
再等一次红圈出现，不点击；过15秒自动锁屏。解锁后应显示绿色「继续监测」，点击绿色按钮；约1分钟后红圈应再次出现。
重复自动锁屏与解锁，但这次不要点绿色按钮；30秒后服务应停止，不再弹出红圈。
如果绿色按钮没有出现，可尝试开启悬浮窗/显示在其他应用上层权限，并确认应用未被后台系统清理。如果仍失败，这是一个未经实测的修改版，需进一步调试兼容性。

固定源代码提交
`apply_patch.py` 是完整修改补丁，它会验证上游文件哈希，不会对其他版本静默应用。
本补丁未新增互联网权限、未要求 Root；应用仍有「设备管理员」锁屏权限，请确认自己信任安装包。若要卸载需先取消设备管理员授权。
本修改版遵循原项目 GNU GPL-3.0-or-later 许可；需保留相应版权和开源许可。
如果要在本机从源码编译，请准备 JDK 17、Android SDK 36、Gradle 8.11.1，执行：
`git clone https://github.com/OlafDrechsler/SleepGuard.git`
`git checkout 0a252e350e18fe8bb2cd9049147051c8a49704f2`
`python3 apply_patch.py /path/to/SleepGuard`
`./gradlew assembleDebug`
独立包名是 `com.sleepguard.greenconfirm`。该版本没有开机自动启动功能；手机重启或系统主动终止服务后，需要重新按一次开始。
